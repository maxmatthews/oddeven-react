## Development

Built with [Create React App](https://github.com/facebook/create-react-app) and deployed to GitHub Pages.

```sh
npm install
npm start      # dev server at http://localhost:3000
npm test       # run tests
npm run build  # production build to ./build
npm run deploy # publish ./build to gh-pages
```
